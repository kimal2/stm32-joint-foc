# CAN 数据格式

经典 CAN，1 Mbps，11 位标准数据帧，DLC = 8。电机 ID 为 1～4。
多字节字段统一采用**大端（高字节在前）、有符号二进制补码**。

## 下发：目标电流

主控 → 全部关节板，CAN ID：`0x080`。

| 字节 | 字段 | 类型 | 单位 |
| --- | --- | --- | --- |
| DATA[0..1] | 1 号电机目标 iq | int16 | 0.001 A/LSB |
| DATA[2..3] | 2 号电机目标 iq | int16 | 0.001 A/LSB |
| DATA[4..5] | 3 号电机目标 iq | int16 | 0.001 A/LSB |
| DATA[6..7] | 4 号电机目标 iq | int16 | 0.001 A/LSB |

编码值 = `round(iq[A] × 1000)`；每块板仅使用自身 ID 对应字段，未使用槽位填 0。

示例：1～4 号分别为 +0.060、−0.060、+1.000、0 A：

```text
ID: 0x080    DATA: 00 3C FF C4 03 E8 00 00
```

## 上报：角度与速度

关节板 → 主控，CAN ID：`0x100 + 电机ID`，即 1～4 号对应 `0x101`～`0x104`。

| 字节 | 字段 | 类型 | 单位 |
| --- | --- | --- | --- |
| DATA[0..3] | 连续机械角度（跨圈展开、卡尔曼滤波） | int32 | 0.001 rad/LSB |
| DATA[4..5] | 机械角速度 | int16 | 0.01 rad/s/LSB |
| DATA[6..7] | 保留 | — | 固定 00 00 |

解码：`角度[rad] = int32值 × 0.001`；`速度[rad/s] = int16值 × 0.01`。

示例：1 号电机角度 −1.250 rad，速度 +3.45 rad/s：

```text
ID: 0x101    DATA: FF FF FB 1E 01 59 00 00
```
